The Members’ Enclosure

Brand-forward delight, grown up. The horse spirit now reads as racing heritage: silks, furlong posts, the horseshoe and the photo finish. The voice is a friend group roasting each other over drinks. It swears in the headline and never in the math, and a Clean mode keeps the jokes. Twenty-two iPhone frames (393 × 852), light and dark, all using the copy deck in spec-v2.md §12.
