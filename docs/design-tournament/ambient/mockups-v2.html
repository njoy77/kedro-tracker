After hours, the game lives in the room.

Round 1 read as a kids' game. This round re-expresses the same thesis (proximity joining, the Lock Screen and Island as the scoreboard, offline phone-to-phone sync) in an adult identity: onyx, bone, one red silk, a little brass, New York serif for the voice, and copy that swears where it lands. Every frame uses the default Unfiltered voice except F22, which shows a table in Clean.

Kedro is rated for mature audiences (frequent profanity). The numbers never swear: scores, rule lines, and the Changes log are plain, and commentary is set in serif italic around them.

The After Hours system

Built on the two colors Kedro already owns: the BrandBackground asset (#0A0A0E) and the red of the script wordmark. Serif speaks, sans counts.
